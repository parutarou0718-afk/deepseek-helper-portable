DeepSeek 助手 · 便携版使用说明
================================

【这是什么】
一个绿色、免安装的 AI 助手（可对话、可让它帮你写代码/改文件）。
已经把所有依赖和环境都打包进去了，拿到电脑上解压就能用，
不用安装 Node.js，也不用管什么版本号。

【怎么用（3 步）】
1. 把压缩包解压到任意目录（路径里尽量不要有中文以外的奇怪字符即可）。
2. 双击「启动DeepSeek助手.exe」。
3. 等几秒，浏览器会自动打开聊天页面（http://127.0.0.1:3080）。

【第一次要填 API Key（重要）】
这个助手要联网调用 DeepSeek 官方模型，需要你自己的 API Key：
1. 打开 https://platform.deepseek.com 注册并登录。
2. 在「API Keys」里创建一个 key，复制（sk- 开头）。
3. 回到聊天页面，按提示（首次会弹 DeepSeek 引导框，或点左下角设置 → 模型）
   把 key 粘贴进去即可。

注意：API 按用量计费，费用由你的 DeepSeek 账号承担，跟打包的人无关。

【系统要求】
- Windows 10 / 11（64 位）
- 需要联网

【其它】
- 关掉浏览器标签页只是关页面，服务仍在后台运行；再次双击「启动DeepSeek助手.exe」
  会直接再打开页面（很快）。
- 想彻底停止服务：双击「停止服务.bat」。
- 助手干活时创建/修改的文件默认放在本目录下的「workspace」文件夹里。
- 出问题时，把本目录下的「dsh.log」文件发给打包的人即可。
